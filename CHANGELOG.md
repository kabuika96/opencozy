# Changelog

## 0.1.0 - 2026-05-03

- Initial public alpha release.
- Secure React PWA for running Codex from a phone or tablet over trusted private access.
- Fastify backend that starts Codex-only PTY sessions.
- WebSocket terminal streaming with mobile keyboard and arrow controls.
- Codex Resume Picker support through `codex resume`.
- Saved LAN app shortcuts.
- Optional macOS launchd helpers for durable local service startup.
