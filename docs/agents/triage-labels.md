# Triage Labels

- `needs-triage`: New or unclear work that has not been shaped.
- `needs-info`: Blocked on missing user, product, or technical information.
- `ready-for-agent`: Clear enough for an automated coding agent to implement.
- `ready-for-human`: Needs a human decision, design judgment, credential, or manual validation.
- `wontfix`: Intentionally not planned.
